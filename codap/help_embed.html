Mixer Builder CSV Import Help

How to use the Mixer Builder

Use the +/- buttons to add or remove categories/bars from the tool. The text boxes underneath each bar allow you to name each stack and specify how many times each outcome appears. You can drag the stacks to adjust how many times an outcome appears. To import into your CODAP sampler, copy the output text or click the copy button. On the CODAP sampler, click the button with the three dots under the device and paste the text into the window that pops up. This will import all the data into your sampler.

How to use the CSV Import

Upload a CSV file, then select a variable from the drop down that appears. To import this data into your CODAP sampler, copy the output text or click the copy button. On the CODAP sampler, click the button with the three dots under the device and paste the text into the window that pops up. This will import all the data into your sampler.
